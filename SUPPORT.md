# Support

For bugs, feature requests, and extension release issues, open an issue in the
main repository:

https://github.com/buchochelliq-labs/intentumdiff/issues

Please include:

- VS Code version and operating system.
- Extension version.
- `intentumdiff` version or commit.
- Whether `intentumdiff.executable` points at a local virtualenv, global command, or
  packaged executable.
- A small reproduction or the relevant `IntentumDiff: Show Output` log excerpt when it
  is safe to share.

For suspected security issues, avoid public issue details and follow the
repository security reporting guidance.
